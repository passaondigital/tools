# Pferde-Huf-Spiel

Ein unterhaltsames Reaktionsspiel, bei dem du Hufeisen anklicken musst, bevor sie verschwinden.

## Spielanleitung

1. Starte das Spiel durch Klicken auf "Spiel starten"
2. Klicke auf die erscheinenden Hufeisen, bevor sie verschwinden
3. Verschiedene Hufeisen-Farben geben unterschiedliche Punkte:
   - Bronze: 10 Punkte
   - Silber: 25 Punkte
   - Gold: 50 Punkte
4. Die Punkte werden mit dem aktuellen Level multipliziert
5. Je mehr Punkte du sammelst, desto höher steigst du im Level
6. Das Spiel endet nach 60 Sekunden

## Schwierigkeitsgrade

- **Leicht**: Langsamere Hufeisen, mehr Zeit zum Klicken
- **Mittel**: Mittlere Geschwindigkeit
- **Schwer**: Schnelle Hufeisen, kurze Reaktionszeit erforderlich

## Starten

Öffne `index.html` in einem modernen Webbrowser.

## Dateien

- `index.html` - HTML-Struktur des Spiels
- `style.css` - Styling und Animationen
